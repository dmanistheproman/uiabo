# Evaluation datasets — Matthew

The new [stance dataset](stance_seed_v1.json) contains 125 provisional claim/passage pairs for comparing the assessment stage. Start with the [labelling guide](STANCE_LABELLING_GUIDE.md) and [review spreadsheet](stance_seed_v1_review.csv). These are controlled stance tests, not an independent end-to-end accuracy benchmark.

For live evidence discovery, use the [43-case retrieval set](retrieval_seed_v1.json), [review guide](RETRIEVAL_REVIEW_GUIDE.md) and [review spreadsheet](retrieval_seed_v1_review.csv). Reference URLs guide human reviewers and are never supplied to the retrieval pipeline. All labels remain provisional until team adjudication.
